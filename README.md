# Persona 3 FES Trainer

Trainer for Persona 3 FES on the PCSX2 emulator via PINE (PCSX2 IPC).

![demo](https://i.imgur.com/VZYuRlA.gif)

## Features

### Party & Character Stats
- Modify character levels, total XP, and current/max HP and SP.
- Adjust main character social stats (Academics, Charm, Courage).
- Edit party setup and member configurations.

### Persona & Skill Editor
- Change current active Personas across available slots.
- Edit Persona stats (Level, ST, MA, EN, AG, LU) and XP.
- Assign custom skills to any Persona skill slot.

### Inventory & Equipment
- Search and add items directly to inventory or update existing item quantities.
- Manage character equipment (weapons, body armor, footwear, accessories).
- Customise equipment attributes, attack, accuracy, defence, and evasion stats.

### General & Misc
- Change the protagonist's first and last name every time. Save & Load to apply changes

## Requirements, Compatibility & Setup

### Requirements

1. **PCSX2** with PINE IPC support enabled.
2. **.NET 8.0 SDK / Runtime** (for building/running the WPF application on Windows).

### Compatibility 

#### IMPORTANT!!!

Has two versions. If you use the New Moon Mod, then use the New Moon Trainer Ver., but if you don't, then use the Vanilla Trainer Ver.

### How to Use

1. Launch PCSX2 and Enable PINE on PCSX2 Setting/Advanced
2. Load **Persona 3 FES**.
3. Run the trainer application.
4. Click **Connect** after you load your save
5. Apply desired stats, inventory adjustments, or persona modifications. To refresh the game's current value, press Connect again
